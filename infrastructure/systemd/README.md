# Systemd service

В проекте приложение запускается как сервис `systemd`, что позволяет автоматически запускать его после загрузки системы, контролировать состояние процесса и автоматически перезапускать приложение при сбоях.

## Основные параметры

| Параметр | Назначение |
|----------|------------|
| `User` | Пользователь, от имени которого запускается приложение |
| `WorkingDirectory` | Рабочая директория приложения |
| `ExecStart` | Команда запуска FastAPI через Uvicorn |
| `Restart=always` | Автоматический перезапуск при завершении процесса |
| `RestartSec=3` | Задержка перед повторным запуском |
| `Environment` | Переменные окружения для подключения к PostgreSQL |
| `WantedBy=multi-user.target` | Автоматический запуск после загрузки системы |

---

## Развертывание

Скопировать unit-файл:

```bash
sudo cp backend.service /etc/systemd/system/
```

Перечитать конфигурацию:

```bash
sudo systemctl daemon-reload
```

Включить автозапуск:

```bash
sudo systemctl enable backend
```

Запустить сервис:

```bash
sudo systemctl start backend
```

---

## Управление сервисом

Статус:

```bash
systemctl status backend
```

Остановка:

```bash
sudo systemctl stop backend
```

Перезапуск:

```bash
sudo systemctl restart backend
```

Просмотр логов:

```bash
journalctl -u backend -f
```

---

## Использование в проекте

После запуска сервис:

- поднимает FastAPI-приложение на **0.0.0.0:8080**;
- использует виртуальное окружение Python;
- подключается к PostgreSQL через переменные окружения;
- автоматически восстанавливается после аварийного завершения процесса.
